# Five Data Analysis Projects

A collection of five beginner-to-intermediate data analysis projects using Python, Pandas, NumPy, and Matplotlib.

These projects provide hands-on practice in data cleaning, exploratory data analysis (EDA), data visualization, and extracting insights from different datasets.

## 📚 Projects

### 01. Airbnb Hotel Booking Analysis

Analysis of hotel booking data to understand booking patterns, cancellations, customer behavior, and other factors related to hotel bookings.

**Topics Covered:**
- Data loading and inspection
- Data cleaning
- Handling missing values
- Exploratory Data Analysis (EDA)
- Booking analysis
- Cancellation analysis
- Data visualization

**Tools:** Python, Pandas, NumPy, Matplotlib

---

### 02. Healthcare Analytics – Doctor Visit Analysis

Analysis of doctor visit data to explore patient visits, demographics, waiting times, and other patterns related to healthcare visits.

**Topics Covered:**
- Dataset exploration
- Data cleaning
- Patient demographics
- Visit analysis
- Waiting-time analysis
- Data visualization

**Tools:** Python, Pandas, NumPy, Matplotlib

---

### 03. Retail Insights – Superstore Data Analysis

Analysis of retail sales data to understand sales, profit, product categories, regions, and customer-related patterns.

**Topics Covered:**
- Sales analysis
- Profit analysis
- Category-wise analysis
- Regional analysis
- Customer analysis
- Data visualization

**Tools:** Python, Pandas, NumPy, Matplotlib

---

### 04. Car Market Trends – CarDekho Data Analysis

Analysis of car-related data to explore prices, brands, fuel types, transmission types, and other factors related to the used-car market.

**Topics Covered:**
- Data exploration
- Data cleaning
- Price analysis
- Brand analysis
- Fuel-type analysis
- Transmission analysis
- Data visualization

**Tools:** Python, Pandas, NumPy, Matplotlib

---

### 05. Global Terrorism Patterns & Trends

Exploratory analysis of global terrorism data to identify patterns and trends across years, countries, regions, and attack-related attributes.

**Topics Covered:**
- Data exploration
- Data cleaning
- Year-wise analysis
- Country-wise analysis
- Region-wise analysis
- Attack-type analysis
- Trend visualization

**Tools:** Python, Pandas, NumPy, Matplotlib

---
